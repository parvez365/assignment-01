jay vaba Access modifier kajkora TypeScript a:

1. Public: je kono property ta sohoja use kora jay. {jemon: akhana samna public use korlaw hoy na korla read hoy  (name:string)}

2. Private: Class ar bahira use kora jay na sob somoy class ar vetora use korta hoba. ono cono class aw access kora jay na. read o kora jaba na write o kora jabana (private name:string)

3. Protected: Class ar bahira use kora jay na but ak class thaka ono cono class a inherit kora use kora jay. (protected name:string)

4. Readonly: Only dakha ja ba and read kora jaba but write kora jaba na. (readonly [name:string])
